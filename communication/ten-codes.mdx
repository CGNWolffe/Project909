Ten-codes compress the most common radio transmissions into a short, recognizable format so that routine traffic clears the channel quickly. A status update that would otherwise take five seconds takes one. They only work, however, when every person on the channel knows exactly what each code means — which is why the list below is the community standard. If you are ever unsure of a code, say what you mean in plain language. Clarity always outranks brevity.

<Warning>
  Ten-codes are **not standardized between agencies**. The same code can mean entirely different things on a neighbouring channel. Any time you are operating alongside fire, EMS, or an outside law enforcement agency, abandon codes entirely and communicate in plain speech.
</Warning>

## Code reference

<Tabs>

<Tab title="Status and Movement">
  Use these codes to report your current status and movement to dispatch. Keep dispatch informed on every change — a unit that has not reported its status cannot be relied upon for assignment.

  | Code | Meaning |
  | ---- | ------- |
  | 10-4 | Acknowledged |
  | 10-6 | Busy, stand by |
  | 10-7 | Out of service |
  | 10-8 | In service, available |
  | 10-9 | Repeat your last transmission |
  | 10-10 | Off duty |
  | 10-17 | En route |
  | 10-23 | On scene |
  | 10-97 | Arrived at destination |
</Tab>

<Tab title="Calls and Requests">
  Use these codes to initiate requests, flag situations, and manage calls in progress. Pair them with a location or additional plain-language detail where the code alone is not enough context.

  | Code | Meaning |
  | ---- | ------- |
  | 10-12 | Civilians present — watch your radio traffic |
  | 10-20 | Location |
  | 10-21 | Call by telephone |
  | 10-22 | Disregard, cancel the call |
  | 10-27 | Licence or driver information request |
  | 10-28 | Plate or registration request |
  | 10-29 | Check for wanted or stolen |
  | 10-38 | Traffic stop |
  | 10-52 | Ambulance required |
  | 10-78 | Request backup |
</Tab>

<Tab title="Priority Traffic">
  These codes carry the highest urgency on the channel. When any of these codes are transmitted, all non-emergency traffic stops immediately and the channel belongs to the unit that called it.

  | Code | Meaning |
  | ---- | ------- |
  | 10-33 | Emergency — clear the channel |
  | 10-80 | Pursuit in progress |
  | 10-99 | Officer in distress — immediate response required |

  <Warning>
    A 10-33 or 10-99 supersedes every other transmission in progress. If you hear either code, release your key immediately, regardless of what you were transmitting.
  </Warning>
</Tab>

</Tabs>

## Common usage examples

```text
// Reporting in-service at the start of a shift
"Dispatch, Sam-7, 10-8."

// Running a plate check during a traffic stop
"Dispatch, Sam-7, 10-28 — King-7-Golf-Nora-3."

// Flagging that a supervisor or civilian is on the channel
"Sam-12, be advised 10-12."

// Calling for backup on a combative stop
"Sam-7, 10-78 — traffic stop escalating at Waterman and Mill, need a second unit."

// Opening an emergency with channel clear
"Sam-7, 10-33 — shots fired, officer down, 200 block of Court Street."
```

<Note>
  Use plain language for anything urgent, unusual, or dangerous. **"Shots fired, officer down"** is faster to process under stress than a code number. When seconds matter, speak plainly.
</Note>
